# Aura Music for Android

Aura Music is a high-fidelity streaming and local music player application for Android built natively with **Kotlin** and **Jetpack Compose**, featuring dynamic Material You aura effects, synchronized live lyrics, an advanced 32-bit DSP Equalizer, and fluid playback controls.

## Features

- **Dynamic Aura Engine**: Atmospheric multi-color radial gradient backdrop dynamically adapting to the album artwork's dominant palette.
- **Fluid Audio Playback**: Background audio controller with seekbar scrubbing, queue management, shuffle, repeat, and sleep timer.
- **Audio Visualizer**: Real-time animated audio soundwave visualizer responding to playback state and tempo.
- **Live Synchronized Lyrics**: Time-coded lyrics display with active line highlighting and tap-to-seek timestamp jumping.
- **Aura FX Graphic Equalizer**: 5-frequency-band equalizer (-10 dB to +10 dB), dynamic presets (Aura Dynamic, Bass Boost, Vocal Glow, Acoustic, Electronic, Rock), 3D spatial virtualizer, and deep bass boost slider.
- **Sleep Timer**: Customizable fade-out sleep timer (15, 30, 45, 60 minutes) with active countdown timer.
- **Music Library & Custom Playlists**: Liked songs collection, custom playlist creation and deletion, and recently played history.
- **Instant Search**: Search across songs, artists, albums, and genres with category cards.
- **Edge-to-Edge Material Design 3**: Fully compliant with Android 16 edge-to-edge system insets and gesture bars.
